# ULogViewer 2026.3 の変更点
 ---

## 新機能
+ 次の組み込みログプロファイルを追加しました：
    + `glog/klog ログファイル`
    + `Go slog/logrus ログファイル`
    + `Hermes Agent ログ`
    + `Hermes Agent ログファイル`
    + `LM Studio サーバーログ`
    + `LM Studio サーバーログファイル`
    + `Log4j/Logback ログファイル`
    + `Loguru ログファイル`
    + `Monolog ログファイル`
    + `Nginx エラーログファイル`
    + `NLog (UDP)`
    + `NLog ログファイル`
    + `Ollama サーバーログ`
    + `Ollama サーバーログファイル`
    + `Ollama サービスログ`
    + `OpenClaw ログファイル`
    + `Ruby Logger ログファイル`
    + `Rust env_logger/tracing ログファイル`
    + `Serilog ログファイル`
    + `spdlog ログファイル`
    + `Spring Boot ログファイル`
    + `vLLM サーバーログファイル`
+ ログプロファイルのアイコンを追加しました。
+ ログプロパティ名を追加しました。
+ `複数のデータグラムにまたがるデータを許可` ログデータソースオプションを追加しました。

## 改善
+ 空のタブにおすすめのログプロファイルを表示し、すばやく選択できるようにしました。
+ `Apache アクセスログファイル` 組み込みログプロファイルの名前を `Apache/Nginx アクセスログファイル` に変更しました。
+ PowerShell 7 および Homebrew でインストールされたコマンドラインシェルによるコマンド実行をサポートしました。

## 動作の変更
+ Windows では PowerShell 7 を優先して使用するようになりました。

## バグ修正
+ `Apple デバイスログ` ログプロファイルで読み取ったログのタイムスタンプを解析できない問題を修正しました。
+ `Apache エラーログファイル` ログプロファイルで Apache 2.4 形式のログを読み取れない問題を修正しました。
+ 細かなバグを修正しました。
