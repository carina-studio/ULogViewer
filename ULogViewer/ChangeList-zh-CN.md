# ULogViewer 2026.2 中有什么改变
 ---

## 新功能
+ 新增日语支持。
+ 支持自动选择日志类型：将日志文件拖动至窗口后，ULogViewer 将会搜索支持它们的日志类型。
+ 支持将目录拖放至窗口以打开其中的日志文件。

## 优化
+ 当变更 `语言` 选项而改变中文环境后不再需要重启应用程序。
+ 编辑脚本时可通过按钮打开脚本日志窗口。
+ 于尚未设置日志类型的标签页中加入可拖动文件的提示。
+ 支持将多个目录拖放至窗口。
+ 应用 macOS 26 的新窗口样式。

## 行为变更
+ 默认不再于建立新标签页后打开日志类型选择界面，可通过 `新建标签页的日志类型选择方式` 选项变更。
+ 同时拖放文件与目录时，会一并打开目录中有效的文件。
+ 当 `新建标签页的日志类型选择方式` 选项为 `自动` 时，拖放目录将不再提供包含工作目录的日志类型选择界面。

## 错误修复
+ 修复无法将 `Noto Sans` 应用至中文环境的问题。
+ 修复更改时间戳格式后，日志读取时间可能未更新的问题。
+ 修复重新启动应用程序后，标签页的自定义标题会丢失的问题。
+ 修复重新启动应用程序后，使用命令列壳层 (Command-line Shell) 执行指令的设置会重置的问题。
+ 修复从单一文件或通过指令读取日志时，未显示标签页的自定义标题的问题。
+ 修复将目录拖放至已设置工作目录的标签页时，未更改其工作目录的问题。
+ 修复潜在的稳定性问题。
+ 其他错误修复。
